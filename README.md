# Aurelia Grand Hotel — Luxury Hotel Website

Aurelia Grand Hotel is a luxury hotel website concept designed to present a polished hospitality experience. It is built with HTML, CSS, and vanilla JavaScript.

[View the live site](https://kushtrimaziri.github.io/aurelia-grand-hotel/)

## Features

- Responsive layout for desktop, tablet, and mobile
- Hotel-focused visual design and imagery
- Interactive elements powered by JavaScript

## Built with

HTML · CSS · Vanilla JavaScript

## Run locally

Open `index.html` in a browser, or use VS Code’s Live Server extension.

## Project files

- `index.html` — website page
- `style.css` — visual styles
- `script.js` — interactive behavior
- `images/` — website images
